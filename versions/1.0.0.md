# Phiên bản 1.0.0

Ngày: 2026-11-03

Phiên bản đầu tiên có log. Gom mọi thay đổi từ lần commit đầu tới nay.

## Thêm
- Tool vào nhà từng UID trong Clash of Critters (LDPlayer 9, ADB), nhận hộp quà MVP nếu có, ghi kết quả từng UID vào `logs/ket-qua-*.csv`.
- Tab **Quét ID**: nhập ID đầu và số lần, mỗi lượt sau cộng thêm 1.
- Bỏ qua người chơi cấp dưới 150 và ghi **false**, không vào nhà. Cấp đọc từ nhãn Lvl trên hàng Results.
- **Tự mở ô nhập UID.** Đang ở sân chính, chế độ Goldrush, panel hồ sơ sai tab (Log hoặc Friends) hoặc còn popup sót thì tool tự bấm về tab Add New. Trước đây tool báo lỗi ngay ở bước đầu. Mất ô nhập giữa chừng cũng tự mở lại.
- Mẫu ảnh mới `friends.png` (icon Bạn bè ở sân) và `community.png` (mốc để tìm tab Add New).
- `.gitignore` bỏ qua `__pycache__/`, `*.pyc`, `logs/` và `list_id.txt`. Các file này đã gỡ khỏi git.
- Skill `ghi-log-phien-ban` và thư mục `versions/` để mỗi lần push có một file log.
- Ghi chú kỹ thuật thêm: bảng các màn hình game, cách kiểm tra sau khi sửa, quy ước git và phiên bản.

## Sửa
- **Đọc cấp bị rỗng với viên Lvl một hoặc hai chữ số.** Mốc cắt chữ số tính theo 46% bề rộng viên, mà viên ngắn thì chữ "l" của "Lvl" lọt vào phần số, nét đó khớp hụt, cả cấp thành rỗng và tool vẫn Visit người cấp thấp. Nay cắt theo 3,25 lần chiều cao nét. Kiểm tra trên emulator thật: cấp 1, 6, 21, 26, 87, 123, 302 đều đọc đúng.
- Đọc rớt chữ số (ví dụ `299` thành `29`) làm ghi false oan. Nay đối chiếu độ rộng viên với số chữ đọc được, lệch thì coi là rỗng.
- Cấp rỗng thì chụp lại tối đa 4 lần trước khi vào nhà, và lưu `logs/khong-doc-duoc-cap.png` nếu vẫn hỏng.
- Bỏ qua chờ dài ở nhà không có quà và ID không tồn tại.

## Lưu ý khi cập nhật
- Tắt hẳn cửa sổ tool rồi mở lại `run.bat`. Cửa sổ đang mở vẫn chạy code cũ.
- Lịch sử git cũ vẫn còn `list_id.txt` và `logs/`. Muốn xóa hẳn phải viết lại lịch sử và force push.
